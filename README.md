## Features
- **Executive Speaking Cadence**: First-person answers ("I", "We", "My") in strict 5–7 word bullets.
- **Interactive Flashcards**: Speed drill mode with keyboard shortcuts (`Space` to flip, `←`/`→` to navigate, `Esc` to close).
- **3-Second Breath Timer**: Visual countdown with Web Audio chime for interview pacing.
- **Natural Cadence Text-to-Speech (TTS)**: 0.95x speaking rate.
- **Mastery Tracking**: Checkboxes with persistence via `localStorage`.
- **Search & Filter**: Real-time filtering across all 108 questions and topics.
- **Mobile-First Responsive**: Horizontal touch slider and mobile-friendly tap targets.
